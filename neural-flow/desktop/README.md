# neural-flow desktop

Notion **🧭 Command Center** 의 **📅 앞으로 7일** 보드를 바탕화면 위젯으로 보여 줍니다.
위젯을 누르면 Notion 앱에서 Command Center(보드 위치)가 열립니다. 그 밖의 기능은 0.9.0에서 모두 뺐습니다.

## 쓰는 법 (처음 한 번)

1. [notion.so/profile/integrations](https://www.notion.so/profile/integrations) → **새 통합** (내부 통합, 콘텐츠 읽기 권한만).
2. Command Center 페이지 오른쪽 위 **⋯ → 연결** 에서 방금 만든 통합을 추가합니다.
3. 통합의 **내부 통합 시크릿**(`ntn_…`)을 앱 설정 창에 붙여넣고 **저장하고 읽기**.

설정 창은 트레이 메뉴 → 설정, 위젯의 ⚙ 버튼, `Ctrl+Alt+M`(macOS `⌘⌥M`)으로 엽니다.

## 동작

- **읽기**: Notion API 로 Command Center 의 `📅 앞으로 7일` 제목 아래 첫 콜아웃을 찾고, 그 안의 글머리 줄
  `10.30 금　11:00 [마감] 제목 · 15:00 제목 · 종일 제목` 을 날짜·시각·태그·제목으로 나눕니다. 읽기만 하고 Notion 을 바꾸지 않습니다.
- **갱신**: 켤 때, 30분마다(설정에서 5~240분), 절전 복귀·화면 잠금 해제 때, 🔄 버튼을 누를 때.
  보드 자체는 Notion 쪽에서 매일 아침 갱신됩니다. 아직 갱신 전이면 지난 날짜는 숨기고 `갱신 전`이라고 표시합니다.
- **위젯**: 오늘부터 날짜별 일정, 오늘·내일 표시, `[마감]` 빨강 · `[필수]` 주황 강조, 날짜별 마감 개수.
- **누르면**: `notion://` 주소로 Notion 데스크톱 앱이 열립니다. 설정에서 **브라우저에서 열기**로 바꿀 수 있습니다.
- **옮기기**: 트레이 → 위젯 옮기기 또는 `Ctrl+Alt+N`(macOS `⌘⌥N`), 다 옮기면 **고정**.
  Windows 에서는 바탕화면에 붙어 있고 Win+D 에도 남습니다. macOS·Linux 에서는 클릭을 받기 위해 일반 창으로 다른 창 뒤에 둡니다.
- **오류**: 토큰이 틀리거나 페이지에 통합이 연결되지 않았으면 이유를 보여 주고, 마지막으로 읽은 보드는 그대로 둡니다.

## 보안

- 토큰은 OS 키체인(safeStorage)으로 암호화해 저장하고, 화면(렌더러)으로 넘기지 않습니다. Notion 요청 헤더로만 보냅니다.
- 저장 파일 `neural-flow.json`(Electron `userData`)도 키체인으로 암호화합니다. 키체인이 없는 Linux 에서는 권한 600 평문입니다.
- 화면 공유·캡처에 위젯이 찍히지 않게 하는 옵션이 기본으로 켜져 있습니다.

## 0.8 에서 올라올 때

일정·메모·로드맵·구글 로그인·AI 코칭 데이터는 첫 실행 때 저장 파일에서 지웁니다. 위젯 위치·크기·업데이트 설정만 이어받습니다.
구글 캘린더 원본, Notion, exam-study 폴더는 건드리지 않습니다.

## 자동 업데이트

설치본은 시작 후·6시간마다 새 릴리스를 확인하고 다운로드 → SHA-256 검증 → 설치·재시작합니다.
설정에서 자동 확인·자동 설치를 끌 수 있고, 체크섬이 없거나 검증에 실패한 파일은 설치하지 않습니다.

## 개발·검증

Node.js 22 이상이 필요합니다.

```bash
cd neural-flow/desktop
npm ci
npm start
npm run check
npm test
npm run test:e2e
npm run dist
```

단위 테스트는 보드 파싱·Notion 요청·오류 안내·저장소 전환·업데이트 검증을 다룹니다.
E2E 는 실제 Electron 앱을 띄우고 가짜 Notion API 로 연결 → 위젯 표시 → 누르면 열기 → 오류 → 업데이트를 확인합니다.
