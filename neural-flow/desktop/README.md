# neural-flow desktop

직접 입력한 일정과 Google 캘린더를 보여주는 바탕화면 위젯·일정 앱입니다.
사용자가 입력한 일정을 LLM과 검토하고, 앱 시작 시 새 버전을 자동으로 설치합니다.
자동 일일 계획·주간 활동 생성·영어·뉴스 브리핑은 실행하지 않습니다.

## 일정 입력

- `Ctrl+Shift+Space` (macOS `⌘⇧Space`) 또는 위젯 `＋`로 빠른 입력을 엽니다.
- `내일 오후 3시 커피챗 2시간` → 미리보기 → 확인 → 저장합니다.
- 관리 창의 **일정 추가**에서는 제목·날짜·시작·종료·반복·메모를 직접 입력합니다.
- 로그인되어 있으면 기본 저장 위치는 Google 캘린더입니다. 설정에서 저장할 캘린더를 선택합니다.
- Google 저장 실패는 오류로 표시하고 입력을 유지합니다. 앱에만 저장하려면 저장 위치를 명시적으로 바꿉니다.
- 로그인 없이 사용하는 로컬 일정과 iCal 읽기 전용 일정은 모바일로 전송되지 않습니다.
- D-day 표시는 로컬 일정에서 지원합니다.

## LLM으로 일정·공지 입력

설정 → **일정·공지 해석**에서 구독 자동 / ChatGPT·Codex / Claude Code / Gemini API / 규칙만을 고릅니다.
자동은 **ChatGPT 로그인한 Codex CLI → Claude Code** 순서로 선택합니다.

- ChatGPT: 이 PC에 Codex CLI를 설치하고 `codex login`으로 ChatGPT 계정에 로그인합니다.
- Claude: 이 PC에 Claude Code를 설치하고 `claude`에서 본인 구독으로 로그인합니다.
- Gemini API는 별도 키·과금 경로이며 명시적으로 선택할 때만 사용합니다.

앱에 구독 비밀번호·토큰을 복사하지 않습니다. CLI의 기존 로그인을 재사용합니다.
CLI를 찾지 못하면 설정에 실행 파일 경로를 입력하고 **연결 확인**을 누릅니다.
Codex의 API 키 로그인은 ChatGPT 구독 연결로 간주하지 않습니다. 실행 시 API 키 환경변수를 제거합니다.
지원되는 구독·모델과 사용량 한도는 각 서비스의 계정 정책을 따릅니다.
연결이 없거나 실패하면 규칙 해석으로 돌아오며 미리보기에 표시합니다.

AI는 사용자가 입력하거나 검토할 때 호출합니다. 공지 원문과 필요한 일정 정보를 선택한 AI에 보냅니다.
입력 미리보기에는 짧은 작성 조언이 표시되고, **오늘 → 일정 코칭**에서는 이번 주 일정의 겹침·빠진 정보·준비 시간을 질문할 수 있습니다.
코칭은 조언·확인 질문만 반환하며 캘린더를 수정하거나 새 루틴을 만들지 않습니다.

공지를 붙여넣으면 행사와 신청 마감을 포함해 최대 20개 항목을 추출합니다.
미리보기에서 종류·제목·날짜·시간·기간·장소·반복·메모를 수정하고 저장합니다.
날짜가 없거나 잘못된 일정은 저장을 막고, 원문은 일정 설명에 보존합니다.
시간을 비우면 종일 일정, 종료·기간을 비우면 1시간입니다. 저장 전에 확인하세요.
일괄 저장 중 일부만 실패하면 실패한 항목만 남겨 재시도 시 이미 저장한 항목을 다시 넣지 않습니다.
입력은 최대 20,000자이며, 더 긴 공지는 나누어 입력합니다.

## 모바일 Google 캘린더

데스크톱과 모바일 Google 캘린더 앱에서 **같은 계정·캘린더**를 사용합니다.
데스크톱에서 저장한 일정은 Google에 저장되며, 모바일에서 입력·수정·삭제한 일정은
데스크톱의 자동 새로고침(약 1분) 또는 **동기화** 버튼으로 읽어옵니다.
앱이 종료되거나 잠겨 있을 때는 갱신하지 않습니다. 표시할 캘린더와 저장 캘린더는 설정에서 선택합니다.
Google 일정 편집은 캘린더 항목을 눌러 Google 캘린더에서 합니다.

### Google 로그인 준비

1. Google Cloud에서 **Google Calendar API**를 활성화합니다.
2. OAuth 동의 화면의 테스트 사용자에 본인 이메일을 추가합니다.
3. OAuth 클라이언트 유형을 **데스크톱 앱**으로 만듭니다.
4. 앱 로그인 화면에 클라이언트 ID·보안 비밀을 입력하고 로그인합니다.

릴리스 빌드는 기존 `NF_GOOGLE_CLIENT_ID`·`NF_GOOGLE_CLIENT_SECRET` 설정도 지원합니다.
비밀값·토큰은 저장소에 넣지 않습니다. 지원되는 OS에서는 키체인으로 암호화합니다.
실제 모바일 연동에는 본인 Google 로그인과 Calendar API 사용 설정이 필요합니다.

## 자동 업데이트

0.5.0부터 설치본은 시작 후 새 릴리스를 확인하고 다운로드 → SHA-256 검증 → 설치·재시작합니다.
입력 중인 일정·공지·열린 일정 편집창이 있으면 저장하거나 닫을 때까지 기다립니다.
설정에서 자동 확인·자동 설치를 끌 수 있습니다. 개발 실행은 자동 설치하지 않습니다.
체크섬이 없는 설치 파일과 검증에 실패한 파일은 설치하지 않습니다.

기존 0.4.1 설치본은 한 번 설정 → 업데이트에서 새 버전을 설치해야 합니다.
새 코드는 릴리스가 배포되어야 기존 앱에 반영됩니다. Windows·macOS 설치 파일은
`desktop-release.yml`에서 테스트 후 `desktop-v0.5.0`으로 배포합니다.

## 기존 데이터

새 설치는 빈 일정으로 시작하며 `state.json`의 추천·루틴을 가져오지 않습니다.
기존 설치는 한 번만 다음 데이터를 정리합니다.

- `데일리 앵커 (state.json)`로 표시된 자동 반복 일정, 생성 출처가 명시된 일정
- 아직 `제안됨` 상태인 활동과 생성 출처가 명시된 활동
- 이전 코칭·영어·뉴스 결과

직접 입력한 일정, 승인한 활동, Google 계정·원격 일정은 보존합니다.
출처가 불명확한 과거 일정과 Google에 이미 등록된 자동 일정은 삭제하지 않습니다.
해당 일정은 캘린더에서 직접 확인하여 삭제해야 합니다.
데이터는 Electron `userData`의 `neural-flow.json`에 저장됩니다.

## 개발·검증

Node.js 22 이상이 필요합니다.

```bash
cd neural-flow/desktop
npm ci
npm start
npm run check
npm test
npm run test:e2e
npm run dist
```

단위 테스트는 저장소 전환·수동 일정 보존·입력 파서·Google 요청·캘린더 갱신을 검증합니다.
E2E는 화면이 있는 환경(또는 Linux의 Xvfb)에서 가짜 Google 서버를 사용합니다.
실제 계정이나 모바일 기기의 동기화를 대신하지 않습니다.

바탕화면 위젯, 빠른 입력, 암호화·PIN·가리기, 업데이트 기능은 계속 사용할 수 있습니다.
관리 창: `Ctrl+Alt+M` (macOS `⌘⌥M`), 위젯 이동: `Ctrl+Alt+N` (macOS `⌘⌥N`).
