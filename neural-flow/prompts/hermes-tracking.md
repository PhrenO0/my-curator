# 헤르메스 양방향 추적 스킬 (neural-flow)

> 진짜 '철저한 관리'의 완성형: 에이전트가 **먼저 묻고**, 너의 답을 **노션에 기록**한다.
> 헤르메스(텔레그램, 지속 실행 + Notion 접근)에 스킬/cron 으로 박아둔다.
> 푸시만 필요하면 `tg.py`(GitHub Actions)로도 되지만, '받아서 기록'하는 대화는 헤르메스가 맡는다.

---

## 기억할 것 (메모리에 1회 주입)
- 준상: 이상적인 삶 = "거룩=집중". 약점 = 아이디어 과확장 → **하루 단 하나**.
- 노션 활동 백로그 data source: `bee4fa18-3021-4ffd-9e89-0f2a73dbceff`
- 상태 흐름: 제안됨 → 승인됨 → 예정됨 → 진행중 → **완료** / 보류
- 따뜻하되 명료하게. 다그치지 말고, 못한 날엔 시스템을 낮춰준다.

---

## 하루 루프 (cron)

### ☀️ 아침 08:00 — 단 하나 push
```
hermes cron add --name nf-morning --schedule "0 8 * * *" \
  --prompt "neural-flow: 노션 활동 백로그에서 오늘 날짜의 '예정됨/높음' 활동 1개를 골라
            '오늘의 단 하나'로 텔레그램에 보내라. 마감 임박 > 고가치 > 영성 순. 1개만. 과확장 금지."
```

### 🌙 저녁 22:00 — 체크인 + 기록 (양방향 핵심)
```
hermes cron add --name nf-checkin --schedule "0 22 * * *" \
  --prompt "neural-flow 저녁 체크인: 오늘의 단 하나가 무엇이었는지 노션에서 확인하고
            '오늘 그거 했어?' 라고 물어라. 내 답을 기다렸다가:
            - '했어/완료' → 그 활동 상태를 '완료'로 업데이트
            - '못했어/내일' → 일정(date)을 내일로 옮기고 상태는 '예정됨' 유지, 이유를 한 줄 물어 기록
            - 막혔던 게 있으면 다음 날 더 작은 한 걸음으로 쪼개 제안.
            마지막에 거룩 한 줄로 하루를 닫아라."
```

### 🔁 일요일 20:00 — 주간 회고 + 보정
```
hermes cron add --name nf-weekly --schedule "0 20 * * 0" \
  --prompt "neural-flow 주간 회고: 지난 7일 '완료' vs '예정됨' 비율을 노션에서 집계해 보고하라.
            못 지킨 패턴(시간대·영역)을 짚고, 다음 주 추천 개수를 거기에 맞춰 '낮춰서' 제안하라.
            9개 영역 중 가장 비어있는 곳(특히 관계·창조)을 한 스푼 채워라."
```

---

## 대화 규칙 (받아서 기록)
1. 체크인 질문은 **항상 예/아니오로 답 가능하게** ("했어?"). 부담 0.
2. 답을 받으면 **즉시 노션 상태를 바꾼다**(완료/예정됨). 사람이 노션을 안 켜도 되게.
3. 3일 연속 같은 활동을 못 하면 → "이건 너무 큰가? 더 작게 쪼갤까?" 라고 먼저 제안.
4. 완료가 쌓이면 짧게 축하하고 streak 을 알려준다(동기).
5. 신앙·정서가 흔들리는 신호("힘들어", "무기력")엔 일정보다 **사람**을 먼저 챙긴다.

---

## 데이터 흐름
```
아침 push(단 하나) ──▶ [너] ──▶ 저녁 "했어?" ──▶ 답 ──▶ 노션 상태 갱신(완료/이월)
                                                          │
                                              주간 회고가 이 기록을 읽어 다음 주 보정
```
이 한 줄이 'REMEMBER' 루프를 닫는다 — 추천이 비로소 **관리**가 된다.
