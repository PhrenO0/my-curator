# 📋 CHAI 공모전 아이디어 기획 — 컨텍스트 브리핑

> 다른 대화 세션에서 CHAI 아이디어를 기획할 때 맨 앞에 붙여넣는 자기완결형 컨텍스트.
> 관련 문서: career-identity.md (커리어 정체성), solo-ai-service-roadmap.md, state.json(career_map).

## 1. 나(준상)는 누구 — 커리어 정체성
- **한 줄:** 기술을 직접 만들 줄 아는 프로덕트 마케터 — **빌더형 PM**
- **심장 문장:** "기술만 아는 사람은 팔 줄 모르고, 마케팅만 아는 사람은 무엇을 만들지 모른다. 나는 그 사이에 서서 **제품과 시장을 잇는다.**"
- **정체성 코어:** CX형 AI 서비스기획·**제품 메이커**. "사용자의 불안·마찰을 다음 행동의 확신으로."
- **커리어 사다리:** 지금(그로스형 MD/PM 지망) → PMM/Growth PM → **PO → CPO/창업가**
- **증거물:** neural-flow(내 삶·커리어를 계측하는 AI 에이전트를 직접 기획·개발·배포) / 영상 제작(영상팀) / 그로스·마케팅 경험
- **도메인:** 1차 = 콘텐츠·크리에이터×AI / 2차 = 공간·프롭테크×AI(장기) / **금융 제외**
- **하고 싶은 것:** 만들 줄 알고(빌더) 팔 줄 아는(그로스) **제품 오너** → 궁극적으로 **창업**. 그래서 "광고 하나"가 아니라 **제품 메이커의 제안**으로 접근하고 싶음.

- **생성형 AI로 브랜드 과제 해결. 형식 무관.** 대학(원)생 개인/최대 3인팀.
- 접수 **7/8~7/30 18:00**. 상금 **2,300만** + **차이커뮤니케이션(광고회사) 채용 우대**.
- 팀: 민욱 등과 함께. 7/13 개인 디벨롭 → 7/15 팀 첫 회의.

## 3. 선택 브랜드 = 청호나이스 (확정)
파트너 3곳(굽네=F&B / 우리은행=금융 / 청호나이스=생활가전) 중 청호 선택 이유:
- 도메인으론 셋 다 내 1·2차 아님 → 기준은 **"어느 브리프가 내 정체성 코어(제품메이커·CX·데이터·AI빌더)를 가장 잘 드러내냐"**
- ⭐ 청호 브리프만 **"20대 신제품 아이디어 제안"을 초대** = **제품 기획(PM) 정체성 발휘 가능** (굽네·우리은행은 광고만 요구)
- 센서 데이터×AI(수질·공기질·수면) 개인화 = CX형 AI 제품 + neural-flow(SENSE→THINK→ACT) 구조
- 구독(렌탈) = 그로스/LTV 사고 / CX·웰니스 = "불안·마찰→확신" positioning 그대로
- **포폴 완성:** 이미 AI전도(제미나이 앰버서더)+마케팅(토스)+빌드(KDT)+콘텐츠(영상) 보유 → 비어있던 **제품기획** 칸을 청호가 채움
- **중복 회피:** 토스(핀테크 마케팅) 이미 진행 → 우리은행(금융) 하면 포폴 겹침

## 4. 청호나이스 브리프 요약
- 종합 생활환경가전(Total Life Care Solution)·웰니스 솔루션. 33년.
- 제품: **정수기(수질) / 공기청정기(공기질) / 침대·매트리스(수면)**. 렌탈(구독) 기반.
- 과제: 신규 고객 확대 브랜드 커뮤니케이션. 택1 = 정수기 / 공청기 / **3종 결합**. **+ 20대용 신제품 아이디어 추가 제안 가능.**

## 5. 승리 앵글 (컨셉 씨앗)
- **핵심 인사이트:** 청호 제품이 관리하는 건 다 **"눈에 안 보이는 것"**(수질·공기질·수면질). 20대는 불안하지만 실감이 안 나서 방치.
- **앵글: "안 보이던 걸 보여주는 AI"** — AI가 데이터를 **실감나는 콘텐츠/영상으로 번역**해 "아 이래서 필요하구나" 확신을 줌.
- **결정타:** 광고 + **20대용 신제품/서비스 제안**(예: 구독+AI 개인 웰니스 리포트, 자취방 3종 케어 번들) → 광고회사 심사위원이 **"광고쟁이가 아니라 기획자"**로 인식.
- **차별화:** 남들=예쁜 AI 광고. 나=**전환 논리(그로스) + AI 영상 + 제품 기획.**

## 6. 디벨롭할 핵심 질문 5개
1. 어느 제품으로? (정수기/공청기/**결합** — 결합이 '제품기획' 어필 최강)
2. 20대가 방치하는 "안 보이는 불안" 구체적으로? (자취방 수질/미세먼지/수면)
3. AI가 그 데이터를 어떤 콘텐츠/영상 씬으로 번역?
4. 제안할 20대 신제품/서비스 1개는?
5. 심사 어필 한 문장 — "왜 이게 이기는가"
