# 1인 AI 외주 → 사업 로드맵

> 목표: **돈 + 창업 도제(직접 파는 BD/GTM) + 포트폴리오**를 한 번에.
> 전제: 나는 빌더다(neural-flow를 혼자 기획·개발·배포). 그래서 인턴/알바 말고 **직접 팔 수 있다.** 직접 파는 것 자체가 창업 도제다.
> 정체성 연결: 빌더형 PM → 이 외주가 "만들 줄 + 팔 줄 아는" 실전 증거가 된다. (career-identity.md)

## 진화 3단계
```
Phase 1 외주(프로젝트)   →   Phase 2 생산화(반복 상품)   →   Phase 3 제품/사업(스케일)
0~2개월: 첫 3고객·상품1검증     2~4개월: 상품화·가격인상·리테이너     4개월+: 버티컬 좁혀 제품화(SaaS)
KPI: 첫 유료고객              KPI: MRR·재구매                  KPI: 반복매출·자동화
```

---

## 1. 무엇을 팔까 (상품 후보)
빌드 가능 + 수요 명확 + 데모 쉬움 순:

| 상품 | 고객 | 가치(그들이 버는/아끼는 것) | 난이도 |
|---|---|---|---|
| ⭐ **리뷰 답변 자동화 봇** | 자영업자·배달 사장 | 리뷰 관리 시간↓, 평점·재방문↑ | 낮음 (블리츠가 하던 것의 1인 버전) |
| ⭐ **인스타/블로그 콘텐츠 자동생성** | 소상공인·1인 브랜드 | 마케팅 콘텐츠 외주비↓, 노출↑ | 낮음 (영상/콘텐츠 스킬 재활용) |
| **예약·CS 챗봇 (카톡채널)** | 병원·학원·소상공인 | CS 인건비↓, 예약전환↑ | 중 |
| **AI 영상·숏폼 제작** | 브랜드·자영업자 | 광고 제작비↓ | 낮음 (즉시 현금, 공모전 결과물=포폴) |
| **문서·업무 자동화 에이전트** | 중소기업 | 반복업무 시간↓ | 중 |
| **분양 현장 AX (B2B)** | 시행사·분양대행 | 상담 효율·전환율↑ | 높음 (2차 도메인 큰 건, Phase 2~3) |

**시작 상품 1개(추천):** **리뷰 답변 봇** 또는 **인스타 콘텐츠 자동생성**.
→ 진입장벽 낮고, neural-flow 코드 재활용 가능, 데모 즉시, 수요 명확.
**상품화 원칙:** 좁게 · 반복 가능하게 · **시간이 아니라 결과(지표)로** 판다.

## 2. 가격 (Pricing)
- **3가지 모델:** ①프로젝트 단건 ②리테이너(월 구독·유지관리) ③성과기반(전환율 등)
- **초기 앵커:**
  - **첫 3고객 = 레퍼런스가** (무료/저렴 + 후기·소개 조건) → 실적·후기 확보용
  - 이후 프로젝트 **30~100만**, 리테이너 **월 20~50만**, AI 영상 **건당 10~50만**
- **가격 정당화:** "제 시급"이 아니라 **"사장님이 이걸로 아끼는 시간·버는 돈"**으로 말한다.
- **세금:** 프리랜서 3.3% 원천징수 / 반복되면 사업자등록 검토.

## 3. 영업 스크립트 (첫 3고객)
**타겟 순서:** ①warm(아는 자영업자·교회·지인·부트캠프 네트워크) → ②크몽/숨고 인바운드 → ③로컬 아웃바운드(인스타 DM)

**무료 오퍼 전략 (레퍼런스 확보):**
> "안녕하세요, AI로 [리뷰 답변 / 콘텐츠 제작]을 자동화하는 걸 만들고 있어요. **무료로 하나 만들어드릴 테니, 괜찮으면 짧은 후기랑 소개만 부탁드려요.** 부담 없이 결과만 보시면 됩니다."

**전환 멘트 (무료 → 유료):**
> "이거 매달 유지·업데이트해드리는 걸 월 [X]만원에 해드려요. 직접 하면 [시간/비용]이 드는데, 그거 아끼시는 거예요."

**채널 셋업:** 크몽 서비스 1개 등록(제목·썸네일·패키지 3단) + 인스타 포트폴리오 계정 + neural-flow를 대표 데모로.

## 4. 전달·운영 (Delivery)
- MVP **1주 내** 전달, 스코프 **좁게** 고정(스코프 크립 = 1인 사업 최대 적).
- 계약 = 간단한 1장(범위·금액·기간·수정횟수).
- 전달 후 **유지보수를 리테이너로 전환**(반복 매출의 핵심).

## 5. 포트폴리오화 (매 프로젝트 = 자산)
- 각 건을 **케이스(문제 → 해결 → 지표)**로 기록 → `experiences.json` 자산 추가 + 포폴 원페이저.
- 이게 자소서·면접의 "만들 줄 + 팔 줄" 증거가 된다.

## 6. 리스크/주의
- ⏰ **시간:** 외주가 네 창업 빌드·학업 시간을 잡아먹을 수 있음 → 주당 상한 정하기.
- 💸 **저평가:** 첫 유료부터는 무료로 하지 말 것(레퍼런스 3건까지만).
- 📏 **스코프 크립:** "이것도 해주세요" → 추가는 추가금.
- 🧾 세금·계약 최소 문서화.

## 7. 이번 주 액션 (블리츠 탈락으로 생긴 시간 활용)
- **Day 1–2:** 시작 상품 1개 확정 + **데모 제작**(neural-flow 코드 재활용)
- **Day 3–4:** warm 리스트 10명 작성 + **무료 오퍼 DM 3건** 발송
- **Day 5:** 크몽/숨고 서비스 1개 등록
- **2주 목표:** 첫 미팅 1건 / **4주 목표:** 첫 유료 고객 1명(또는 무료 레퍼런스 3건 완료)

## 8. 큰 그림 연결
- 첫 상품(리뷰봇/콘텐츠) = 현금 + 실적.
- 반복되면 **콘텐츠×AI(1차 도메인)** 버티컬로 좁혀 제품화.
- **분양 AX**(공간×AI 2차 도메인)는 Phase 2~3의 **첫 B2B 상품**으로 승격 → 시행사 1곳 레퍼런스가 사업의 씨앗.
- 종착: 외주 → 반복상품 → SaaS/사업 = career-identity.md의 PO/CPO·창업가 라인과 정확히 일치.
