# 🎨 감각 어휘 사전 (lexicon)

분야별 전문가가 감각을 서술할 때 쓰는 **공용 술어**를 모아둔 곳.
에이전트가 준비지의 "감각 팔레트"를 만들 때 여기서 골라 쓴다.

- 여기 담는 것: 술어·형용어·기법 이름 (누구의 문장도 아닌 그 분야의 공용어)
- 여기 담지 않는 것: 특정 저자의 문장 (그건 준비지에 출처와 함께 짧게 인용)

읽다가 좋은 표현을 만나면 해당 파일에 한 줄씩 계속 더한다. **사람이 키우는 파일이다.**

| `music.md` | 음악비평 + 무드→장르 매핑표 | ✅ 씨앗 작성됨 |
