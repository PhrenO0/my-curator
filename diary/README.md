# 일기 (Diary)

개인 일기 보관소입니다. 이 저장소는 **비공개(private)** 이므로 내용은 본인만 볼 수 있습니다.

## 폴더 구조

```
diary/
├── README.md          # 이 파일 (안내 + 목차)
├── ARCHITECTURE.md    # 일기 준비 에이전트(diary-prep) 설계
├── TEMPLATE.md        # 새 일기 작성용 템플릿
├── new.sh             # 오늘 자 일기 파일을 만들어 주는 스크립트
├── inbox.md           # 떠오른 조각을 던져두는 곳 (준비지의 씨앗)
├── lexicon/           # 분야별 감각 어휘 사전 (사람이 계속 키움)
├── prep/              # 생성된 준비지 (YYYY/MM/YYYY-MM-DD-prep.md)
└── YYYY/
    └── MM/
        └── YYYY-MM-DD.md
```

## 일기 준비 에이전트

키워드를 던지면 관련 지식·전문가 감각 어휘·배경음악을 모아 **준비지** 한 장을
차려주는 에이전트를 설계해 두었습니다. 설계는 [ARCHITECTURE.md](ARCHITECTURE.md),
구현은 Lv.1부터 단계적으로 진행합니다.

날짜별로 파일 하나씩, `연/월` 폴더에 나눠 담습니다. 파일명이 곧 날짜라 정렬·검색이 쉽습니다.

## 새 일기 쓰기

```bash
./diary/new.sh          # 오늘 자 파일 생성 후 경로 출력
./diary/new.sh 2026-08-27   # 특정 날짜로 생성
```

이미 파일이 있으면 덮어쓰지 않고 기존 경로만 알려 줍니다.

## 검색

```bash
grep -rn "키워드" diary/          # 본문 검색
ls diary/2026/08/                 # 특정 달에 쓴 일기 목록
```
